Features

Everything you need for Resolve-compatible media

Convert any audio or video format FFmpeg supports into professional codecs that Davinci Resolve on Linux can work with natively.

Any Audio Codec In

FLAC, WAV, and AAC conversions accept any input codec FFmpeg supports — MP3, AAC, Opus, Vorbis, PCM, and more.

DNxHD & DNxHR

Smart resolution detection automatically selects DNxHD for ≤1080p and DNxHR SQ for 4K+ content, in professional .mov containers.

Batch Processing + ETA

Select multiple files, convert them in one go. A single progress dialog shows pending files and an ETA based on actual media duration.

Safe Replace

Originals are backed up before replacement, output is validated with ffprobe before overwriting, and failed conversions never touch your files.

Native KDE Dialogs

Progress bars and confirmations use kdialog — feels native on KDE Plasma, no GTK/GNOME dependencies needed.

Audio-Only Support

Works with pure audio files like .m4a, .mp3, .flac — outputs .flac, .wav, or .m4a directly without video container overhead.

Conversions

Available actions in the context menu

Right-click any video or audio file in Dolphin to see these options under Davinci Resolve Conversions.

Action Output Format Behaviour
Audio to FLAC (delete original) Video → .mkv · Audio → .flac FLAC Replaces original
Audio to FLAC (new file) Video → .mkv · Audio → .flac FLAC Keeps original
Audio to WAV (keep container) Video → same ext (PCM inside) WAV Replaces original
Audio to WAV (.wav) Audio-only → .wav WAV Replaces original
Audio to AAC (replace) Video → .mp4/.mov · Audio → .m4a AAC Replaces original
Audio to AAC (new file) Video → .mp4/.mov · Audio → .m4a AAC Keeps original
DNxHD/DNxHR (replace) .mov (auto codec by resolution) DNx Replaces original
DNxHD/DNxHR (.mov) .mov (auto codec by resolution) DNx Keeps original
Installation

Up and running in 30 seconds

Works on any Linux distribution with KDE Plasma. Auto-installs dependencies on Debian/Ubuntu and Arch.

Dependencies
ffmpeg Media conversion
kdialog Progress dialogs
qdbus / qdbus6 D-Bus updates
notify-send Notifications
bc Math calculations 
# Arch Linux
sudo pacman -S ffmpeg kdialog qt6-tools libnotify bc

# Ubuntu / Debian
sudo apt install ffmpeg kdialog qdbus-qt5 libnotify-bin bc

# Install the tool
git clone https://github.com/shrippen/dolphin-davinci-audio-tools.git
cd dolphin-davinci-audio-tools
chmod +x install.sh && ./install.sh

# Restart Dolphin
kquitapp5 dolphin && dolphin
